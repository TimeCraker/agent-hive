# 任务 INSPPF：my-portfolio 线上健康巡检

一句话任务：对 **https://asterforge.top**（个人主页 / 商业矩阵入口）做一次**只读**线上健康巡检（可用性 / 访客路径 / 性能 / 死链），产出带严重度分级的问题清单。

## 背景（已核实事实，勿重新考古）

- 个人主页 + 商业矩阵入口（有 hub/ 子站结构）。Next.js + Prisma + Three.js + Tailwind。
- 2026-10-05 刚做过移动端性能优化（Perf 56 → 70+，字体 preload 归因）——本次巡检可验证优化是否在线上生效。
- 只打线上 HTTP，不做 git 写操作。

## 步骤

1. **可用性**：HTTP/HTTPS、证书、重定向、首页/静态资源抽样状态码与响应时间。
2. **访客路径走查（只读）**：首页 → 主要导航/矩阵入口 → 子站链接可达性。不提交任何表单。
3. **性能**：PSI 免费接口 mobile+desktop 各一次（重试 ≤2）；失败降级 curl 计时 + 资源清单（关注：字体加载策略是否体现 preload 优化、首屏资源体积）。
4. **死链**：首页 + 最多 3 个关键页，限深 2、并发 ≤2、间隔 ≥500ms；矩阵入口的外链逐一 HEAD 验活。
5. 汇总写报告。

## 红线

- 只读：不提交表单、不登录；失败重试 ≤2；拿不到的如实标注。
- 除报告外零写入；无 git 操作。Windows 11 + PowerShell。

## 验收标准

报告含五节 + P0-P3 问题分级清单（含「10-05 性能优化是否在线上生效」的判断）。
