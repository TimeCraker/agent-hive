## 背景（已核实事实，勿重新考古）

- 社区小饭桌点餐服务（顾客点链接点餐 + 商家管理端）。Next.js 16 + Prisma + SQLite。2026-08-23 HTTPS 验收全绿、2026-08-28 微信真机复验通过。
- 已知历史事实（来自近期审计，供参照不必重查）：生产库曾有 Agent D 测试走查数据（7 菜/8 单）；收款码 payQrCode 上传状态存疑——**你巡检时观察展示层是否正常即可，不查库**。
- 本巡检只打线上 HTTP，不做任何 git 写操作。

## 步骤

1. **可用性**：HTTP/HTTPS、证书、重定向、首页与静态资源抽样状态码/响应时间。
2. **顾客关键路径走查（只读极限）**：打开点餐链接形态的页面 → 浏览菜单/菜品展示 → 到「提交订单」前的最后一步为止。**绝不点提交、绝不加购物车触发写接口、绝不进商家端、绝不登录**。每步记录可达性与展示异常。
3. **性能**：PSI 免费接口（`https://www.googleapis.com/pagespeedonline/v5/runPagespeed?url=<编码后URL>&strategy=mobile`，mobile+desktop 各一次，重试 ≤2）；失败降级 curl 计时 + 首页资源清单。
4. **死链**：首页 + 最多 3 个关键页，限深 2、并发 ≤2、间隔 ≥500ms。
5. 汇总写报告。
