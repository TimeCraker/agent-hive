# 任务 INSPLK：lekao 线上健康巡检

一句话任务：对 **https://lekao.asterforge.top** 做一次**只读**线上健康巡检（可用性 / 关键路径 / 性能 / 死链），产出带严重度分级的问题清单。

## 背景（已核实事实，勿重新考古）

- K12 培训机构 AI 助教工作台，Next.js 16 + Prisma + next-auth。免费模式：签到得 T-Coin，无付费充值。
- 本巡检**只打线上 HTTP**，不使用仓内代码、不启动本地服务、不做任何 git 写操作（仓只是你的落脚 cwd）。

## 步骤

1. **可用性**：HTTP/HTTPS、证书有效期、http→https 重定向、www/裸域解析、关键公开端点状态码与响应时间（首页、静态资源抽样 2-3 个）。
2. **关键路径走查（游客视角，只读）**：首页加载 → 主要导航页 → 登录页入口。**绝不注册、绝不登录、绝不提交任何表单**。记录每步的可达性与明显前端报错（JS 错误可从响应/控制台线索推断的部分；无法推断就标注）。
3. **性能**：优先调 PSI 免费接口 `https://www.googleapis.com/pagespeedonline/v5/runPagespeed?url=<编码后URL>&strategy=mobile`（无需 key，mobile+desktop 各一次，失败重试 ≤2）；失败则降级：curl 计时（TTFB/总耗时）+ 首页 HTML 资源清单（JS/CSS/图片数量与体积）。
4. **死链**：爬首页 + 最多 3 个关键页的链接（内链为主），限深 2、并发 ≤2、每请求间隔 ≥500ms（礼貌爬取，别打挂站）。外链只测可达性 HEAD。
5. 汇总写报告。

## 红线

- **生产只读**：不下单、不注册、不登录、不提交表单、不触发任何写操作（含「签到」按钮背后的接口——那是写操作）。
- 失败请求重试 ≤2；拿不到的数据如实标「未获取到」。
- 除报告文件外零写入；无 git 操作。
- Windows 11 + PowerShell。

## 验收标准

报告含五节（可用性/走查/性能/死链/问题分级清单 P0-P3），每个问题附证据（状态码/耗时/URL）。
