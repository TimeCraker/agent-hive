# QW · 越权访问文案改为「无权访问」

## 背景
简历编辑页（apps/web/src/app/(editor)/resume/[id]/page.tsx）当用户访问不属于自己的简历时，
API 返回 403「无权访问此简历」，但页面展示的错误提示是「加载失败」——不准确且让用户困惑。

## 要求
1. 找到简历编辑页的加载错误处理逻辑（可能在 page.tsx 或其子组件的错误态渲染中）
2. 把越权场景（403）的用户可见文案改为「无权访问此简历」
3. 保持其他错误（网络异常等）文案不变
4. 不修改 API 层（后端已正确返回 403）
5. 不碰无关 dirty 文件

## 禁止

- 不修改 schema
- 不运行 pnpm install/build
- 不 git commit
