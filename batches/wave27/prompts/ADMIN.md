## 步骤

1. **模块枚举**：从路由清单（走查文档）与 /admin 首页导航枚举全部模块（当前应为 8 个，如 用户/简历/AI 配置/订单核销/公告/数据统计 等——以实际为准）；逐个进入确认可达、导航高亮正确。
2. **权限**：
   - admin 登录 → /admin 可进、导航完整。
   - 【E2E】普通账号 → 直达 /admin 各模块 URL：被拒（重定向/403 页），截图。
   - 未登录 → 重定向登录。
3. **每模块只读走查**（8 个模块逐个）：
   - 列表：渲染、分页、行信息完整（脱敏截图）。
   - 筛选：每模块至少一组筛选（状态/关键词/日期任选实际有的）：结果正确、可清除。
   - 空态：构造空筛选条件（如不存在的关键词）→ 空态文案合理。
   - 表单验证：**只打开新建/编辑表单看校验，不提交**（或提交必填空表单看校验提示后取消/关闭）——禁止真实提交任何写操作。
   - console 无新增错误；1440px 截图目检，关键模块 390px 一轮（后台可以桌面为主，但至少抽 2 个模块验证 390 不破版）。
4. **写操作登记**：所有「保存/发布/核销/调整/删除」按钮只验证存在与二次确认弹层出现，然后取消；台账/结果表把这些登记为「未测（只读约束）」。
5. **缺陷处理**：简单缺陷（导航高亮、文案、裁切、筛选清除按钮失效等）可修：commit（中英文）→rebuild→回归；涉及权限/鉴权的缺陷**只取证交回**（这是复杂清单项）；独占文件只记不修。
6. **登记**：走查文档 ADMIN 分区：模块×（导航/列表/筛选/空态/验证）矩阵结果 + 台账。
