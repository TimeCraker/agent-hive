# MPF: 个人作品集主站架构与资产引用体检

## 任务目标
对 `my-portfolio`（主站 asterforge.top，Next.js + Prisma/SQLite）执行类型检查、仓库结构规范性审计及原画/动效资产引用完整性核查。

## 执行步骤
1. 进入工作目录 `my-portfolio`，执行 `git status` 确认工作区状态。
2. 运行类型检查：执行 `npm run typecheck`（`tsc --noEmit`）。
3. 运行仓库结构规范检查：执行 `npm run check:structure`。
4. 核查原画与动效资产：检查 public 目录下的吉祥物/原画帧与 mascot 引用路径是否完整无损坏。
5. 检查活文档与配置一致性：核对部署配置与主页项目矩阵。
6. 将体检事实与自评结论整文件覆盖写入报告。

## 红线约束
- 只读体检与架构审计，不得篡改数据库内容或擅自修改原画资源；
- 严禁产生未追踪文件遗留；
- 真实记录检查结果。

## 验收标准
- 类型检查与结构检查输出明确；
- 资产完整性核查有具体结论；
- 生成结构化体检报告。

## 报告要求
覆盖写入文件路径：
`waves/wave30/reports/MPF-report.md`
报告包含：
1. 项目概况与检查时间
2. TypeScript 类型检查与仓库结构审计结果
3. 静态资产与原画动效引用完整性走查
4. 综合健康度评估（A/B/C）与风险点说明
5. 自评结论（是否达标）
