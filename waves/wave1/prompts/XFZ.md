# XFZ: 社区小饭桌点餐服务质量门与契约体检

## 任务目标
对 `xiaofanzhuo`（社区小饭桌点餐服务，线上 xiaofanzhuo.asterforge.top）执行质量门回归与构建检查，验证点餐核心状态机契约的稳定性。

## 执行步骤
1. 进入工作目录 `xiaofanzhuo`，执行 `git status` 确认工作树状态。
2. 运行单测质量门：执行 `npm test`（即 `vitest run`），核查订单状态流转与金额计算用例。
3. 运行构建冒烟：执行 `npm run build`，验证 Next.js 页面与路由静态生成是否完全无报错。
4. 检查数据层契约：检查 `prisma/schema.prisma` 与数据迁移状态。
5. 将体检事实与自评结论整文件覆盖写入报告。

## 红线约束
- 只读体检与质量门验证，不得修改生产数据库结构与业务逻辑；
- 严禁产生脏提交或遗留未追踪产物；
- 测试或构建如果存在异常，在报告中详实记录，不私自扩围重构。

## 验收标准
- Vitest 单测有数字化通过率与耗时；
- Next.js 构建输出结果明确（页面数、静态/动态路由分布）；
- 生成结构化体检报告。

## 报告要求
覆盖写入文件路径：
`waves/wave30/reports/XFZ-report.md`
报告包含：
1. 项目概况与检查时间
2. 单测执行结果（用例通过情况）
3. Next.js 构建结果与性能指标
4. 业务契约健康度分析（点餐、快照、订单状态机）
5. 自评结论（是否达标）
