# LK: 乐考 AI 助教工作台质量门与健康度体检

## 任务目标
对 `lekao`（K12 机构 AI 助教工作台，线上 lekao.asterforge.top）执行质量门回归与健康度审计，输出明确的数字化健康体检报告。

## 执行步骤
1. 进入工作目录 `lekao`，执行 `git status` 确认当前工作树状态。
2. 运行单测质量门：执行 `npm test`（即 `vitest run`），记录通过用例数与耗时。
3. 运行类型检查：执行 `npm run typecheck`（`tsc --noEmit`），检查是否存在 TypeScript 类型错误。
4. 运行代码规范检查：执行 `npm run lint`，记录 warning 或 error 数量。
5. 审计活文档与代码一致性：检查 `README.md` 与实际命令/端点配置是否存在漂移。
6. 将体检事实与自评结论整文件覆盖写入报告。

## 红线约束
- 本任务为只读诊断与质量门审计，严禁擅自重构或修改生产业务代码；
- 严禁提交无关改动或修改密钥配置；
- 若测试或类型检查报错，如实记录在报告中作为验收事实，不掩饰问题。

## 验收标准
- Vitest 单测有明确的 PASS / FAIL 统计数字；
- `tsc --noEmit` 有明确的退出状态；
- 生成完整的自包含体检报告。

## 报告要求
覆盖写入文件路径：
`waves/wave30/reports/LK-report.md`
报告包含：
1. 项目概况与检查时间
2. 单测执行结果（通过数/失败数/总数/耗时）
3. 类型检查与 Lint 检查结果
4. 潜在风险与健康度评级（A/B/C）
5. 自评结论（是否达标）
